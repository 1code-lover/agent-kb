# ThinkRAG 知识库智能问答 V1 实施计划

## 1. 计划目标
在不偏离当前代码主链路的前提下，完成知识库智能问答的能力收口，让“导入、管理、问答、来源展示、历史追踪”形成完整产品闭环。

## 2. 分阶段计划

### 阶段 A：主流程可用
目标：
- 跑通文件导入、网页导入、问答主流程。

关键任务：
1. 统一知识库与问答相关文档为中文 UTF-8。
2. 校验 `/api/kb/*` 与 `/api/chat/*` 核心接口可用。
3. 校验 Query / File / Web / Manage 页面主流程。
4. 完成一轮主流程冒烟测试。

阶段产出：
- 可演示的知识库智能问答闭环。
- 主流程测试结果。

### 阶段 B：结果可信
目标：
- 强化回答来源和错误提示，提升问答可信度。

关键任务：
1. 统一回答结果中的来源展示口径。
2. 梳理常见错误提示文案。
3. 完成来源与错误路径测试。
4. 补充使用说明和已知限制。

阶段产出：
- 来源展示说明。
- 异常场景验证记录。

### 阶段 C：管理与扩展
目标：
- 为后续多知识库、多行业知识库演进建立清晰边界。

关键任务：
1. 梳理多知识库/多行业知识库扩展方案。
2. 评估索引隔离与配置扩展点。
3. 完成实施方案与测试方案。

阶段产出：
- 多知识库扩展方案。
- 后续实施优先级建议。

## 3. 角色与责任
- 产品：控制范围，确保主线始终是知识库智能问答。
- 后端：维护 `/api/kb/*` 与 `/api/chat/*` 主链路。
- 前端：优化 Query / File / Web / Manage 页面体验。
- 测试：覆盖主流程、异常路径、回归场景。

## 4. 风险管理
1. 不将主线重新扩成 Agent 工作台重构。
2. 文档、代码、测试的命名和范围保持一致。
3. 每阶段结束前检查 UTF-8 编码和内容一致性。

## 5. 质量门禁
- 核心接口通过率 = 100%
- 主问答场景通过率 >= 95%
- 阻断问题 = 0
- 中文 UTF-8 文档统一完成

## 6. 当前下一步建议
1. 保持现有测试通过状态。
2. 继续收口产品与实施文档。
3. 单独整理“知识库问答测试方案”和“测试报告”。
