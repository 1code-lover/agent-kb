# ThinkRAG 知识库智能问答 V1 需求追踪矩阵（RTM）

## 1. 说明
- 目的：确保需求、实现、测试和验收一一对应。
- 原则：每条核心需求至少对应 1 个实现入口和 1 组测试验证。

## 2. 需求追踪矩阵

| 需求ID | 需求描述 | 实现入口 | 测试类型 | 验收标准 |
| --- | --- | --- | --- | --- |
| FR-01 | 支持文件导入知识库 | `/api/kb/file/import`、`frontend/KB_File.py` | 接口测试、主流程测试 | 文件可导入，结果可反馈 |
| FR-02 | 支持网页导入知识库 | `/api/kb/web/import`、`frontend/KB_Web.py` | 接口测试、主流程测试 | URL 可导入，失败有提示 |
| FR-03 | 支持知识库文档列表查询 | `/api/kb/list`、`frontend/KB_Manage.py` | 接口测试、回归测试 | 文档列表可读取 |
| FR-04 | 支持知识库文档删除 | `/api/kb/docs`、`frontend/KB_Manage.py` | 接口测试、回归测试 | 删除结果明确，列表同步更新 |
| FR-05 | 支持知识库智能问答 | `/api/chat/query`、`frontend/Document_QA.py` | 接口测试、场景测试 | 能返回回答 |
| FR-06 | 问答结果展示来源信息 | `chat_service.query`、Query 页面 | 场景测试、回归测试 | 回答附带来源/片段信息 |
| FR-07 | 支持历史消息查询与清理 | `/api/chat/history` | 接口测试、回归测试 | 历史可查、可清 |
| NFR-01 | 中文 UTF-8 文档统一 | `docs/` | 文档检查 | 无英文主方案遗留 |
| NFR-02 | 主流程错误有明确提示 | `api/routers/chat.py`、`api/routers/kb.py` | 异常路径测试 | 无静默失败 |
| NFR-03 | 接口职责清晰 | `/api/kb/*`、`/api/chat/*` | 设计评审 | 知识库与问答边界明确 |

## 3. 场景测试映射

| 场景ID | 场景描述 | 覆盖需求 |
| --- | --- | --- |
| SC-01 | 上传本地文件后可在知识库列表看到文档 | FR-01, FR-03 |
| SC-02 | 导入网页后可发起相关问题查询 | FR-02, FR-05 |
| SC-03 | 删除指定文档后列表更新 | FR-04 |
| SC-04 | 基于知识库回答问题并展示来源 | FR-05, FR-06 |
| SC-05 | 查询历史消息并清理历史 | FR-07 |
| SC-06 | 模型配置或索引异常时返回可读错误 | NFR-02 |

## 4. 发布门禁
1. FR-01 至 FR-07 覆盖率 100%。
2. SC-01 至 SC-05 全部通过。
3. 阻断问题为 0。
4. 方案文档统一为中文 UTF-8，且主线描述一致。
