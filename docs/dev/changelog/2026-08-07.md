# 2026-08-07 开发记录

## 本地知识库稳定性与前端依赖安全收口

### 变更内容
1. **导入与检索链路加固**
   - `/api/kb/file/import` 改为从真实 multipart form 中读取 `relative_paths`，兼容目录上传的多值字段。
   - BM25 兼容节点过滤改为基于纯正文判断，避免 metadata 拼接内容让空正文节点进入 BM25 构建。
   - Office 类型识别收窄为当前依赖已验证的 `.docx` 与对应 MIME，避免过度承诺未验证格式。

2. **粮仓 QA 评测可信度增强**
   - `scripts/run_grain_qa_eval.py` 增加 `cases_sha256`、运行参数、来源数量、来源 `kb_id` 列表和缺失 `kb_id` 计数。
   - 评测逻辑把存在 sources 但缺少 `kb_id` 的情况判为 KB 隔离失败。
   - 新增脚本级回归测试覆盖缺失来源 `kb_id`、目标 KB 正常通过和用例文件 hash 追踪。

3. **OCR 运行时与诊断链路修复**
   - conda `agent-kb` 环境补齐 `paddleocr==3.7.0` 与 `paddlepaddle==3.2.2`。
   - OCR 初始化前默认设置 PaddleX ModelScope 模型源，并保留用户显式环境变量。
   - OCR 初始化前预加载并修复 `langchain.text_splitter` 兼容桥，避免 PaddleOCR/PaddleX 污染同名模块后导致问答失败。
   - 图片、扫描 PDF、mixed batch 诊断脚本补充 macOS/Linux/Windows 字体候选，扫描 PDF 诊断样本提高字号和画布宽度。

4. **前端依赖安全收口**
   - 升级 Vite 到 `8.2.1`，`@vitejs/plugin-react` 到 `6.0.5`。
   - 用项目内轻量 router 替代 `react-router-dom`，保留顶层页面切换、`Link`、`useLocation`、`useNavigate`、Hash/File 场景和未知路径回退。
   - 本地 router 对协议 URL、双斜杠和反斜杠导航做拒绝，避免引入 open redirect 类风险。
   - `npm audit --json` 当前为 0 vulnerabilities。

5. **文档与本地环境记录**
   - `AGENTS.md` 增加 macOS conda `agent-kb` 环境说明。
   - `docs/project.md` 更新到 2026-08-07 当前进度、验证结果和剩余风险。
   - `评审建议.txt` 覆盖为最新复核意见。
   - 清理旧 Streamlit 状态文件中的占位注释。

### 剩余风险
- mixed batch 正向问答会返回多个候选 sources；首要/目标文档、preview 和关键词均命中，但如果产品要求更少引用噪声，需要继续明确证据返回契约并收口 top-k、rerank 或前端展示策略。
- 多知识库仍是共享索引加 metadata 逻辑隔离，不是物理多索引隔离。
- 粮仓 QA 样本当前为 30 条，指标全绿但不能替代更大规模真实资料验收。
