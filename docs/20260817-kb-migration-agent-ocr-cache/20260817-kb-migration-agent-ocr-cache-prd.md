# 历史迁移、OCR 基准、只读 Agent 与 Embedding 下载控制 PRD

- 文档日期：2026-08-17
- 需求目录：`docs/20260817-kb-migration-agent-ocr-cache/`
- 目标版本：桌面端本地知识助手下一阶段

## 1. 背景

当前版本已完成多知识库物理索引隔离、Embedding 缓存缺失恢复入口和基础 OCR 版面/规则表格增强，但仍存在四个影响升级安全、质量可信度和开放能力的缺口：

1. 历史共享索引中的非 `default` 数据不会自动迁移至 `storage/kbs/{kb_id}/`。
2. OCR 缺少可重复执行的真实扫描件基准集，跨页或连续表格块容易被拆散。
3. Agent API 面向本机 UI，缺少只读开放接口和知识库级授权令牌。
4. Embedding 缓存下载只能看到粗粒度状态，缺少进度、磁盘预检和取消能力。

## 2. 产品目标

### G1 历史知识库迁移／重建助手

安全扫描历史共享索引，根据节点元数据生成迁移计划；迁移前备份；按知识库重建独立索引；提供可重试、可审计、可回滚的迁移结果。

### G2 OCR 真实扫描件基准与连续表格识别

建立仓库内可复现、无外部依赖的扫描件基准资产及质量评估；识别同一页内被普通文本隔开的表格块以及跨页延续表格，并输出稳定 Markdown 表格和诊断信息。

### G3 Agent 只读开放接口与知识库授权令牌

提供独立的 `/api/open/v1` 只读开放层。调用方使用可撤销、仅保存摘要的令牌，只能读取被授权知识库并执行只读搜索/问答，不得访问命令、文件系统、审批和会话写接口。

### G4 Embedding 下载进度、磁盘预检和取消

下载前检查目标文件系统剩余空间；下载期间返回阶段、字节数和百分比；用户可取消正在进行的准备任务；取消后不得触发模型预热，并可重新开始。

## 3. 用户角色

- **本地用户/管理员**：升级旧数据、管理开放令牌、观察和控制模型下载。
- **外部只读 Agent/自动化**：使用令牌查询指定知识库。
- **开发与测试人员**：运行 OCR 基准并比较质量门槛。

## 4. 功能需求

### FR-MIG 历史迁移助手

- **FR-MIG-01 扫描**：只扫描默认历史 `storage/`，按节点 `metadata.kb_id` 分组；`default` 不迁移；缺失、非法或未知 KB 的节点进入阻断/异常清单。
- **FR-MIG-02 dry-run**：生成稳定计划，至少包含来源、目标、知识库、文档数、节点数、目标是否已存在、预计空间、异常项和计划摘要；不得修改存储。
- **FR-MIG-03 备份**：正式迁移前，将历史索引复制到带批次号的备份目录并生成文件 SHA-256 清单。
- **FR-MIG-04 重建**：按 KB 在同文件系统临时目录构建独立索引，保留文本、元数据、关系和可用 embedding；校验后原子切换到最终目录。计划必须统计缺失 embedding；默认阻断，只有显式选择 `recompute_missing_embeddings` 才允许重算。
- **FR-MIG-05 幂等**：相同计划已成功迁移时重复执行不得重复插入；目标非空且不匹配时默认拒绝覆盖。
- **FR-MIG-06 校验**：比较源/目标节点数、ref_doc 数和内容摘要；输出每 KB 成功、失败、跳过状态。
- **FR-MIG-07 失败与重试**：失败不得删除历史索引；成功 KB 与失败 KB 分开记录；允许仅重试失败 KB。
- **FR-MIG-08 回滚**：历史来源始终保持不变；回滚仅隔离或删除 manifest 记录的本批次新建目标目录，并恢复迁移前 runtime 指向。仅允许处理本工具创建且清单验证通过的批次。
- **FR-MIG-09 状态与进度**：API 和前端展示状态、当前 KB、完成数、总数、错误和批次号。

### FR-OCR OCR 基准与连续表格

- **FR-OCR-01 基准资产**：仓库保存至少 6 个可复现基准样本，分为自制打印后扫描/拍摄的 `captured` 小型资产与确定性生成的 `synthetic_degradation` 资产，覆盖倾斜、低对比、双栏、单页连续表格、跨页表格和表格夹杂段落。
- **FR-OCR-02 金标**：每个样本包含期望阅读顺序、表头、关键单元格和页边界金标。
- **FR-OCR-03 评估**：脚本输出字符召回、行顺序、表格单元格召回、表头延续和连续表格合并指标，并支持质量阈值退出码。
- **FR-OCR-04 同页连续表格**：几何上同列、列数相同且垂直间距合理的相邻表格块合并为一个 Markdown 表格；普通段落是硬边界，不跨段落合并，也不误并入表格。
- **FR-OCR-05 跨页延续**：仅当上一页表格位于页尾、下一页表格位于页首且列结构匹配时识别为延续；重复表头按标准化文本相似度去重；保留 `[Page N]` 可追溯标记。
- **FR-OCR-06 诊断**：输出 table block 数、merged block 数、continued page 数、重复表头去除数。

### FR-OPEN 只读开放接口和授权令牌

- **FR-OPEN-01 令牌创建**：本地管理 API 创建命名令牌，明确授权 KB 列表和有效期；明文令牌只返回一次。
- **FR-OPEN-02 安全存储**：磁盘只保存令牌 SHA-256/HMAC 摘要、前缀、权限、状态、创建/到期/撤销时间；使用原子写入和 `0600` 权限。
- **FR-OPEN-03 鉴权**：开放接口要求 `Authorization: Bearer <token>`；缺失、错误、过期、撤销均拒绝。
- **FR-OPEN-04 KB 授权**：请求知识库必须是令牌授权集合子集；不允许空范围回退到全部知识库。
- **FR-OPEN-05 只读能力**：开放层仅提供健康检查、授权信息、知识库列表、检索/问答；不暴露导入、删除、命令执行、文件读取、审批、设置写入和令牌管理。
- **FR-OPEN-06 审计**：记录 token_id、时间、路径、KB 范围、结果码和耗时，不记录令牌明文或完整问题内容。
- **FR-OPEN-07 撤销**：管理员可列出、撤销令牌；撤销即时生效。
- **FR-OPEN-08 默认本机安全**：令牌管理接口仅接受本机来源，并使用独立管理密钥；开发测试可注入固定密钥。长期管理密钥不得注入普通浏览器渲染器，本阶段提供本机 CLI 管理令牌。

### FR-EMB Embedding 下载控制

- **FR-EMB-01 预检**：开始前解析缓存目标目录，计算磁盘可用空间和保守所需空间；不足时拒绝启动并返回结构化原因。
- **FR-EMB-02 进度**：状态包含 `phase`、`bytes_downloaded`、`bytes_total`、`progress_percent`、`progress_mode=exact|estimated`、`current_file` 和更新时间。第三方下载器不提供精确总量时，只能报告已落盘字节与明确标记的估算百分比。
- **FR-EMB-03 取消**：提供取消 API；状态进入 `cancelling`，下载函数在安全检查点终止并进入 `cancelled`。
- **FR-EMB-04 清理**：取消或失败后清理本次临时目录，不删除此前完整缓存。
- **FR-EMB-05 重试**：`failed` 或 `cancelled` 后可再次开始；并发开始仍保持单任务幂等。
- **FR-EMB-06 预热门禁**：仅缓存完整且校验成功时重置 runtime 并触发预热。
- **FR-EMB-07 前端**：展示空间预检、阶段、进度条、当前文件、取消和重试。

## 5. 非功能需求

- 所有持久化清单和令牌文件使用原子写入。
- 不记录令牌明文、外部凭证、文件正文或完整问题。
- 迁移、下载任务同一时刻各最多一个；状态线程安全。
- 新增 Python 模块覆盖率不低于 80%。
- API 保持统一响应格式；错误使用明确 HTTP 状态码。
- 保持 `llama-index-core==0.11.19`，并按仓库实际使用的 LlamaIndex integration packages 显式声明依赖；避免在 runtime baseline 中重新引入顶层 `llama_index` metapackage。
- 不依赖 macOS Developer ID、签名或公证完成开发验收。

## 6. 验收标准

1. dry-run 对真实/构造历史共享索引不产生任何文件变更。
2. 迁移成功后每个 KB 位于独立目录，跨库查询不可见，节点/文档摘要校验通过。
3. 迁移中注入失败时原始索引和已生成备份可用，失败 KB 可重试。
4. OCR 基准全部可离线复现，质量脚本达到文档阈值；连续表格的表头、关键单元格和页边界测试通过。
5. 未授权、过期、撤销令牌均无法访问；授权令牌只可查询指定 KB；开放层不存在写操作。
6. 令牌存储中不存在明文，审计日志不泄露令牌和问题正文。
7. Embedding 空间不足时不启动；进度单调不回退；取消后不预热；可重新下载。
8. Python 非 slow、Web 单元测试、Vite build、Electron 测试全部通过。

## 7. 范围边界

- 不迁移无法通过 `metadata.kb_id` 确认归属的节点。
- 不提供多用户账户系统、云端密钥托管、互联网暴露反向代理或计费限流。
- OCR 基准使用可合法入库的合成/自制扫描资产，不引入第三方受限文档。
- 取消能力要求下载适配层可协作取消；不保证强制终止第三方库内部不可中断的单次系统调用。
- 本需求不包含 macOS 正式签名、公证和 stapling。
