# Task Plan: KB Upload Target Selection

## Goal
修复知识库页面在未明确选择目标知识库时仍可上传/导入的问题，确保文件上传和网页导入都绑定一个已登记且 active 的知识库，并同步测试与开发文档。

## Scope
- 前端知识库选择状态与创建/删除联动
- 文件上传、网页导入、文档列表的未选择保护
- 目标知识库可视化提示与可访问性
- 前端回归测试、构建、必要的后端定向回归
- 人工测试指南、项目进度与开发故事同步

## Phases
1. [complete] 读取现状、需求与测试方式，记录实现事实
2. [complete] 先写失败回归测试，确认问题可复现
3. [complete] 实现显式知识库选择和相关 UI/状态联动
4. [complete] 执行自动化测试、构建、格式检查与浏览器烟测
5. [complete] 更新测试记录、项目文档和开发故事

## Constraints
- 不静默回退到 default；default 也必须由用户显式选择
- 未选择 active KB 时禁止文件上传和网页导入
- 新建 KB 成功后自动选中；删除当前 KB 后清空选择
- 文档列表在未选择 KB 时不发送请求
- 不改动或覆盖工作区中其他未提交成果
- 遵循 TDD；不得新增 占位语句

## Validation Gates
- 回归测试先失败、实现后通过
- 前端构建通过
- 相关后端 KB 测试通过
- git diff --check 通过
- 浏览器验证关键交互及请求 kb_id
