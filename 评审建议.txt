本轮实现已完成 resourceRoot/runtimeRoot 拆分、Python 数据/模型根目录透传、默认 embedding 随包和 package verifier 门禁。TDD 定向测试、Python 非 slow 全量、Web 测试/build、Electron 全量和真实 packaged Agent/Ollama E2E 均有证据。首次真实 E2E 发现 Python __pycache__ 修改 Resources，补充 PYTHONDONTWRITEBYTECODE 后第二次 E2E 已证明 Resources 前后 114 项文件哈希完全一致，代码与发布实现审核通过，可以进入测试报告和提交阶段。

优点：
1. packaged Python script 仍从 Resources 读取，cwd、storage、session、config、KB、receipt 和日志均进入 userData/runtime，避免把可写数据放入签名 bundle。
2. `NORTHAGENT_DATA_ROOT`、`NORTHAGENT_MODEL_ROOT` 和 `PYTHONDONTWRITEBYTECODE` 由 spawn 环境显式注入，且 runtimeRoot 初始化采用 fail-closed。

4. 真实 packaged API E2E 覆盖 Ollama 原生 Agent 直连和坏云端模型到动态 Ollama 候选的自动 fallback，返回精确答案、明确“已自动切换” step、来源/目标和 `fallback_applied=true`。
5. 首次 E2E 的负结果没有被掩盖：Resources 生成 __pycache__ 后定位到 Python bytecode 写入并补测试/环境修复，第二次验证才作为通过证据。
