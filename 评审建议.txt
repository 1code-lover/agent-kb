代码与测试报告评审建议（2026-08-15，Agent 直连 Ollama 与自动 fallback）

评审结论：
本轮实现完成了原目标中真实遗漏的 Agent 高级模式模型韧性：Ollama 不再被硬编码拒绝，云端或本地模型出现可恢复错误时会复用统一候选探测并自动切换一次。实现、测试、最新 ad-hoc 打包和测试报告相互一致，代码审核通过，可以进入开发故事沉淀和提交阶段。

正式 Apple 签名、公证、stapling 与安装后回归仍受外部凭证阻塞；本机也没有 Ollama 服务或本地模型，因此不得宣称正式 macOS release 或真实 Ollama 推理 E2E 已完成。

优点：
1. provider 调用被拆为配置读取、共享 JSON 请求、OpenAI 兼容调用和 Ollama 原生调用，云端兼容性与本地协议均有独立测试。
2. `run_llm_chat` 复用 `attempt_model_fallback`，切换后重新读取当前配置，只重试一次；没有引入第二套候选逻辑。
3. fallback 后真实重试失败会覆盖健康状态为 `unavailable`，避免保留误导性的 `fallback_applied`。
4. 对外 fallback 结果主动裁掉 `selected.api_key`；receipt 和日志只保留错误类别、候选数、来源/目标和最终模型。
5. Agent API 返回 `fallback`、`model_health`，step 摘要明确显示“已自动切换到 provider / model”，前端已有 model options 刷新会立即展示状态。
6. Ollama 常见 `model 'name' not found` 已纳入 `model_unavailable` 分类；真实云端隔离链路证明缺失模型可自动切换到可用候选。
7. 验证完整：定向 `74 passed`，Python 全量 `790 passed, 1 deselected`，Web `89 passed` 且 build 通过，Electron `64 passed`，最新 `build:mac` 和 `verify:package` 通过。
