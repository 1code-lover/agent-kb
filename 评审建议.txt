最新评审建议（2026-08-11）

优点：
1. 后端把 fallback 探测结果沉到 `fallback_attempts`，前端再用 `probeSummary` 展示，模型健康链路比之前更可诊断。
2. Models 页和 Agent 页同步展示相同摘要，排查时不会出现一边有提示、另一边没有提示的割裂感。
3. 相关单测和 `cd webapp && npm run build` 已通过，当前增量没有引入明显回归。

需要改进的地方：
1. 现在页面只展示最近一次探测摘要，多候选失败的完整细节还看不到；如果一次 fallback 经过多个候选，排障仍要回到 health payload 或日志。
2. 这次只是文本级提示增强，还没有做更细的浏览器视觉回归，窄屏下长模型名是否换行自然还需要再看一眼。

具体建议：
1. 保持当前实现先合并，下一步如果要继续增强诊断能力，可以把 `fallback_attempts` 做成可展开明细。
2. 后续桌面回归时顺手确认一次模型页和 Agent 页的提示在窄宽度下没有挤压布局。
